# Quick Start

For complete setup instructions, see [README.md](README.md).

For development and Git hooks setup, see [CONTRIBUTING.md](CONTRIBUTING.md).

## Quick Commands

- **Run agent**: `python main.py`
- **Verify setup**: `python -m tests.test_setup`
- **Find endpoint models**: `python -m tests.test_endpoint`

## Key Files

- `README.md` — Full documentation, features, and setup
- `CONTRIBUTING.md` — Development workflow and Git hooks
- `.env.example` — Configuration template
- `requirements.txt` — Python dependencies
